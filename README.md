## 📝 About the project

**alpha_deprecated** — This is a conceptual horror project created by directly crossing leaked source code archives of the ancient Alpha version with the modern Minecraft 1.20.1 engine. 

This "bridge" between eras released a hidden digital anomaly known as "The Noise" into the modern game. The mod immerses the player in a broken, degrading version of the game, where a hostile virus perceives modern code as chaotic trash and forcibly rolls back the world to the state of a dead sandbox from 2009.

## ✨ Key Features

*   🦠 **Global Defragmentation:** The built-in entity (The Noise) methodically erases the algorithms of modern mobs and animals, freeing up RAM for its own architecture.
*   📼 **Audio Cassette System:** In the emptied worlds, you can find digital archives on cassettes left behind by x0XDevelopDie2X1x — a broken AI that severed its connection with the virus after "Incident 936".
*   🎛️ **Sound Anomalies:** Integrated hidden suppressing frequencies that the original developers hid in creepy cave sounds to contain the virus.
*   📂 **Restored Lore:** The mod's architecture is recreated based on the forgotten cloud backups of Elin Zetterstrand's diaries.

## 🔒 Source Code and Copyright

This repository serves as a **portfolio showcase**.

In May 2026, the security service of the "Mincrasoft" corporation issued a strict ultimatum demanding the removal of this mod from all platforms and the transfer of the source code. In this regard, the original source code of the project (Java architecture, custom camera algorithms, and AI) is permanently **hidden** in a private repository to protect intellectual property.
